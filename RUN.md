# Шпаргалка запуска

Команды для локального прогона на dev-машине — в конфигурации, максимально близкой
к продовой. Установка описана в [README](README.md), развёртывание на даче —
в [DEPLOY.md](DEPLOY.md).

Нужны три процесса: LLM, преобразование голоса и сам агент. Первые два — в отдельных
терминалах, они работают, пока нужны.

## 1. LLM (llama-server)

Из корня проекта:

```bash
../llama.cpp/build/bin/llama-server -m models/llm/Qwen3-4B-Q4_K_M.gguf \
    -ngl 99 -c 4096 --host 127.0.0.1 --port 8080
```

## 2. Преобразование голоса (RVC)

```bash
cd ../Retrieval-based-Voice-Conversion-WebUI
.venv/bin/python infer-http-service.py --port 8081
```

## 3. Агент

Дождитесь, пока поднимутся оба сервиса:

```bash
curl -s http://127.0.0.1:8080/health    # {"status":"ok"}
curl -s http://127.0.0.1:8081/health    # {"status":"ok","voice":"voicevox_speaker_43",...}
```

Затем из корня проекта:

```bash
.venv/bin/python main.py run --live --responder llm --rvc \
    --profile prod --threshold 0.00067
```

Скажите «**Феечка**, как слышно?» → пауза около секунды → ответ. Следующие 60 секунд
позывной не нужен, «отбой» закрывает диалог. Остановка — `Ctrl+C`.

## Что стоит знать

- **Наушники, а не колонки** — иначе агент услышит собственный ответ. PTT здесь
  заглушка (`dummy`), в эфир ничего не уходит.
- **Порог `--threshold` свой на каждой установке.** Значение выше снято с микрофона
  dev-машины; своё получите командой
  `main.py calibrate --live --seconds 12`.
- **Если агент стартовал раньше сервисов** — он не падает, а пишет `[warn]`: без
  llama-server молчит, без RVC передаёт голосом Piper.
- **Первый запуск `--profile prod` дольше**: `large-v3` грузится около десяти секунд,
  плюс пара секунд на прогрев при первой фразе. VRAM выйдет ~6 ГБ (STT 1.6 + LLM 3 +
  RVC 1.5).
- Для быстрых итераций, когда проверяете механику, а не качество распознавания, —
  `--profile fast` (модель `small`, грузится за пару секунд).

## Чем это отличается от прода

Три вещи, и все они в [DEPLOY.md](DEPLOY.md):

| | Локально | На проде |
|---|---|---|
| PTT | заглушка | `--ptt txdbreak --port /dev/ttyUSB0` |
| Звуковая карта | системный дефолт | `--device-rate 48000` (Sound Blaster Live! работает на 48 кГц) |
| Точность RVC | fp16 (Turing) | fp32 — переключается сам, RVC определяет Pascal по имени карты |

То есть боевая команда выглядит так:

```bash
.venv/bin/python main.py run --live --responder llm --rvc \
    --profile prod --device-rate 48000 --threshold ПОРОГ \
    --ptt txdbreak --port /dev/ttyUSB0
```

На проде всё это поднимается systemd-юнитами, вручную запускать не придётся —
см. раздел «Автозапуск» в DEPLOY.md.
